# HR Analytics using Python

## Overview :
This project presents an end-to-end HR Analytics using Python. The dataset was cleaned, preprocessed, analyzed, and visualized using Python to identify employee attrition patterns and key HR insights that support data-driven decision-making.

## Dataset :
- HR Analytics Dataset

## Tools Used :
- Python
- Jupyter Notebook (PyCharm)
- Pandas
- NumPy
- Matplotlib

## Workflow :
1. Imported the HR Analytics dataset into Python.
2. Cleaned and preprocessed the dataset using Pandas.
3. Performed Exploratory Data Analysis (EDA).
4. Created visualizations using Matplotlib.
5. Generated business insights based on employee and HR metrics.

## Key Analysis :
- Employee Attrition Analysis
- Department-wise Analysis
- Job Level Analysis
- Performance Rating
- Data Visualization
 
## Project Features :
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insights
